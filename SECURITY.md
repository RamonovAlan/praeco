# Security Policy

## Supported versions

Praeco is currently a private release candidate. Security fixes are applied to
the latest commit on `main`; no stable public version is supported yet.

## Reporting a vulnerability

Email [alanramon71@gmail.com](mailto:alanramon71@gmail.com) with the subject
`Praeco security report`.

Include a concise description, affected version or commit, reproduction steps,
and impact. Do not include live credentials, owner content, database copies, or
other people's personal data. Do not open a public Issue for a vulnerability.

You should receive an acknowledgement within seven days. No bug-bounty program,
payment, or response deadline is promised. Please allow time for investigation
before public disclosure.
